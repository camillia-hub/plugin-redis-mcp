# Redis MCP

Reads and writes a Redis instance. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/redis-mcp

Installs from the Camillia hub as `redis-mcp-f7ea63`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
